# 图书馆还书机器人系统

面向图书馆还书场景的移动机器人原型。系统通过 RFID/NFC 采集图书标识，利用摄像头识别书架条码/二维码，Arduino 控制巡线底盘，并在匹配目标书架后触发停车与机械臂取放流程。

> 本仓库整理自 2023 年项目源码。硬件地址、串口、相机索引、机械臂姿态与阈值均为当时测试环境的配置，部署前需要重新标定。

## 系统流程

```text
RFID/NFC 读取图书 UID
        ↓
维护车载书籍槽位
        ↓
Arduino 灰度巡线 + 超声安全停车
        ↓
摄像头识别书架条码/二维码并匹配
        ↓
串口停车 → MyCobot 机械臂抓取/归还
```

## 硬件与通信

- 上位机：Jetson Nano / Raspberry Pi（Python）
- 底盘控制：Arduino，串口默认 `/dev/ttyACM0`、9600 bps
- 图书识别：PN532（I2C）读取 RFID/NFC UID
- 书架定位：USB 摄像头 + OpenCV + pyzbar
- 运动控制：8 路灰度传感器（I2C 或串行版本）、超声模块、四轮电机驱动
- 机械臂：MyCobotSocket

## 运行说明

1. 在 Linux/ARM 上安装 Python 3.8+ 与系统级 ZBar 依赖。
2. 安装 Python 依赖：`pip install -r requirements.txt`。
3. 根据实际设备修改串口路径、相机索引、PN532 接线及 `merge2.py` 中的机械臂 IP/端口。
4. 将 `src/arduino/line_follow/line_follow.ino` 与同目录头文件烧录到 Arduino，并完成灰度传感器和超声阈值标定。
5. 先运行 `RFID_v2.1.py` 采集书籍 UID；再运行集成脚本进行书架匹配和归还。

## 实现说明

- RFID 模块读取的是图书 RFID/NFC 卡的 UID，并存入最多 5 个车载槽位。
- 书架匹配由摄像头识别的条码/二维码完成；匹配后 Python 通过串口向 Arduino 发送 `S` 以停车。
- 底盘采用 8 路灰度传感器的加权偏差完成巡线。超声距离低于代码阈值时执行安全停车。
- `merge2.py` 为实验环境下的流程脚本，其中的机械臂关节角度为预设标定值。

## 关键设计决策

### 固定槽位的车载书籍状态

车载书架在代码中建模为 5 个固定槽位；每个槽位保存一本书的 RFID/NFC UID，空槽位以占位符表示。书架码与图书 UID 匹配后，程序根据匹配 UID 找到对应槽位，并将该槽位恢复为空，而不是删除列表元素。

这样可以保证软件中的槽位索引始终与车上的物理取书位置一一对应：即使归还顺序与装载顺序不同，后续图书也不会因为列表重排而被机械臂从错误位置取走。

### 分阶段集成

系统按“图书入库”和“沿线归还”两个阶段运行：

1. PN532 读取图书 UID，去重后装入未占用的车载槽位。
2. Arduino 按灰度传感器反馈执行巡线，并在超声距离低于阈值或收到上位机停车命令时停止。
3. 摄像头持续识别书架条码/二维码；识别结果与当前车载 UID 匹配时，Python 经串口发出停车指令。
4. 机械臂按匹配到的槽位执行预设抓取/放置动作，随后更新该槽位状态。

## 部署与排障记录

- Jetson Nano / Raspberry Pi 侧应先确认 I2C、串口、USB 摄像头均被系统识别；PN532 的 I2C 总线可用 `i2cdetect -y -r 1` 检查。
- 摄像头识别失败时，优先检查设备接入、设备节点和 OpenCV 相机索引；当系统未发现视频设备时，视觉流程不会启动。
- Jetson Nano 运行视觉任务时应关注温度与资源占用，并根据实际硬件配置采取散热措施。
- RFID UID、串口路径、相机索引、超声阈值以及机械臂关节角度均依赖当时测试环境，迁移设备时需要逐项重新标定。

## 注意事项

本项目为硬件原型源码，尚未抽象为可直接复用的软件包。运行前请在脱离地面的安全状态下验证电机方向、急停逻辑、机械臂运动范围及串口权限。
